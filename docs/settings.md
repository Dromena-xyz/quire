# Settings

Open Quire's settings from **Settings, Quire**. The options are grouped by area.

## Updates

- **Version.** The installed version of Quire.
- **Check for updates.** Quire watches for new releases and tells you when one is
  out, so an off-directory install still stays current. Use this to check on
  demand.

## Scenes

- **Scene template.** A template applied to each new scene file. If you use the
  Templater plugin, its syntax is supported, so a new scene can start from your
  own boilerplate.
- **Write scene metadata.** When on, Quire writes a small ordering property into
  each scene's frontmatter. Leave it off to keep scene files free of any metadata
  you did not add; the index still tracks order either way.
- **Multi-select modifier.** Which modifier key (for example Alt or Cmd/Ctrl)
  selects more than one scene at a time in the list.

## Workspace

- **Hide pane on startup.** Keep the Quire pane closed when Obsidian launches, and
  open it yourself when you want it.

## Switching from Longform

- **Import a project.** Opens the importer. See
  [Importing from Longform](importing-from-longform.md) for how it works and what
  it does and does not touch.

## License

The License section is where you activate and manage your key: paste the key and
**Activate**, see your **Status** and **Activations**, **Check status now**, and
**Deactivate this vault on this device** to free an activation. Full details are
in [Licensing](licensing.md).
