# Getting started

## 1. Install and activate

Install Quire with [BRAT](https://github.com/TfTHacker/obsidian42-brat) or a
direct download (see the [main page](https://github.com/Dromena-xyz/quire)), then
enable it in Obsidian's Community plugins list.

Open **Settings, Quire**, paste your license key under **License**, and click
**Activate**. Quire is now ready. See [Licensing](licensing.md) for how
activation and devices work.

## 2. Make a project

Open the Quire pane from the ribbon icon, or run the command **Open Quire
panel**. Use the new-project action to create one: pick a name and a location,
and Quire makes a folder containing an index file (`_quire_index.md`) that tracks
your scenes.

## 3. Add scenes

A scene is just a Markdown note. Add one from the field at the bottom of the
scene list, or insert one above or below an existing scene from its menu. Each
scene you add becomes a file in the project, listed in order in the pane.

## 4. Write, arrange, and assemble

That is the whole loop:

- **Write** in the scene files like any other note.
- **Arrange** them in the [scene list](the-scene-list.md): drag to reorder, nest
  scenes under one another, and group as your draft takes shape.
- **Read or revise the whole thing** in a [Galley](galley.md), which stitches the
  scenes into one document and syncs your edits back to each file.
- **Export** with [Compile](compile.md) when you are ready for a single
  manuscript.

Coming from Longform? See [Importing from Longform](importing-from-longform.md).
